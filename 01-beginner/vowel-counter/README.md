# Vowel Counter 🔤

Finds the number of vowels in a word.

## 📋 Features
- Finds number of vowels in a word
- Finds number of consanants in a word
- Simple logic

## 🛠️ How to Run
```bash
python vowel-counter.py
```

## 📖 How to Use
1. Run the program
2. Enter word

## 💡 Concepts Used
- Loops and conditions
- List data structure
