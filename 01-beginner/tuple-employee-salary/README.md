# Tuple Employee Salary 💵

Finds highest salary in a tuple of employee salaries.

## 📋 Features
- Holds salaries in a tuple
- Has a range of 3
- Simple logic

## 🛠️ How to Run
```bash
python tuple-employee-salary.py
```

## 📖 How to Use
1. Run the program
2. Enter Salaries

## 💡 Concepts Used
- Loops and conditions
- Tuple data structure
- User input validation

Highest Salary is Sheshanth (Totally Not Real)
