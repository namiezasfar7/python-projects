# Combined Grocery Tracker 🧺

Finds bill amount and displays bucket items.

## 📋 Features
- Holds prices in a dictionary
- Holds items in a list
- Calculates discounts
- Has a range of 3

## 🛠️ How to Run
```bash
python combined-grocery-tracker.py
```

## 📖 How to Use
1. Run the program
2. Enter item
3. Enter quantity

## 💡 Concepts Used
- Loops and conditions
- Mixed data structure

## 📸 Sample Output
Input Item (Apple, Milk, Bread) : Apple
Input Quantity : 20
