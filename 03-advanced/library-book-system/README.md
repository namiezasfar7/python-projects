# Library Book System 📖

A library book management system built in python.

## 📋 Features
- Shows late books
- Calculates fines
- Prints output

## 🛠️ How to Run
```bash
python library-book-system-v2.py
```

## 📖 How to Use
1. Run the program
2. Enter name
3. Enter book title
4. Enter days

## 💡 Concepts Used
- Loops and conditions
- Functions
- Error checking
- Data structures
- User input validation
- Simple data management
