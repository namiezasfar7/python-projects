# Coffee Shop 🍵

A bill counter simulated and built in python.

## 📋 Features
- Check coffee prices
- Check coffee quantities
- Prints bill

## 🛠️ How to Run
```bash
python coffee-shop-v2.py
```

## 📖 How to Use
1. Run the program
2. Enter coffee type
3. Enter coffee quantities

## 💡 Concepts Used
- Loops and conditions
- Functions
- Data structures
- User input validation
- Simple data management
