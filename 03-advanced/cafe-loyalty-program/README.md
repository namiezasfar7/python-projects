# Cafe Loyalty Program 🍵

A console-based cafe loyalty program simulation built in python.

## 📋 Features
- Check available points
- Redeems free coffee
- Shows summaries

## 🛠️ How to Run
```bash
python cafe-loyalty-program.py
```

## 📖 How to Use
1. Run the program
2. Choose from the menu options
3. Follow on-screen instructions

## 💡 Concepts Used
- Loops and conditions
- Functions
- Data structures
- User input validation
- Simple data management

## 📸 Sample Output
Add Purchase
Redeem Free Coffee
Show Points
Show Summary
Exit
