# Movie Ticket System 🎟️

A movie ticket system built in python.

## 📋 Features
- Shows seat types
- Shows seat quantities
- Calculates bill
- Prints output

## 🛠️ How to Run
```bash
python movie-ticket-system.py
```

## 📖 How to Use
1. Run the program
2. Enter seat types
3. Enter seat number
4. Enter seat quantity

## 💡 Concepts Used
- Loops and conditions
- Data structures
- User input validation
- Simple data management
