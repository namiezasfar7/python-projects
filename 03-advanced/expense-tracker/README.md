# Expense Tracker 💵

An expense tracker built in python.

## 📋 Features
- Seperately stores expenses
- Gives warning if spent more than budget
- Prints output

## 🛠️ How to Run
```bash
python expense-tracker.py
```

## 📖 How to Use
1. Run the program
2. Enter category
3. Enter expense amount

## 💡 Concepts Used
- Loops and conditions
- Functions
- Data structures
- User input validation
- Simple data management
