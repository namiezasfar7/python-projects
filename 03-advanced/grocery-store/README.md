# Grocery Store 🥬

A bill calculator for a grocey store built in python.

## 📋 Features
- Seperately stores bill amounts
- Simple logic
- Prints output

## 🛠️ How to Run
```bash
python grocery-store-v2.py
```

## 📖 How to Use
1. Run the program
2. Enter product type
3. Enter quantity

## 💡 Concepts Used
- Loops and conditions
- Functions
- Data structures
- User input validation
- Simple data management

## 📸 Sample Output
Input Product Type (Rice, Sugar, Milk, Eggs) 
Input Product Quantity
