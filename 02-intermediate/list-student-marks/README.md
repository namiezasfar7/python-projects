# List Student Marks 9️⃣0️⃣

Finds total and average of a students marks.

## 📋 Features
- Holds marks in a list
- Has a range of 5
- Simple logic

## 🛠️ How to Run
```bash
python list-student-marks.py
```

## 📖 How to Use
1. Run the program
2. Enter marks

## 💡 Concepts Used
- Loops and conditions
- List data structure

## 📸 Sample Output
Marks is [50, 34, 78, 23, 90]
Total is 275
Average is 55
