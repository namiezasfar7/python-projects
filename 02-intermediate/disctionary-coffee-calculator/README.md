# Dictionary Coffee Calculator ☕

Finds bill amount for specific coffee types.

## 📋 Features
- Holds coffee tpes in a dictionary
- Simple logic

## 🛠️ How to Run
```bash
python dictionary-coffee-calc.py
```

## 📖 How to Use
1. Run the program
2. Enter coffee type
3. Enter coffee quantity

## 💡 Concepts Used
- Dictionary data structure
- User input validation

## 📸 Sample Output
Bill Amount : 20,000
