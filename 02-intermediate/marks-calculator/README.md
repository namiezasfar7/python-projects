# Marks Calculator 9️⃣0️⃣

Finds average and highest marks of a class.

## 📋 Features
- Holds marks in a dictionary
- Has a custom range - User entered

## 🛠️ How to Run
```bash
python marks-calculator.py
```

## 📖 How to Use
1. Run the program
2. Enter name
3. Enter marks

## 💡 Concepts Used
- Loops and conditions
- Dictionary data structure

## 📸 Sample Output
Average Mark is 50
Highest Mark 90
